# LAZZO — landing (desktop)

Sitio informativo del juego LAZZO. HTML + CSS + JS plano, scroll fluido con [Lenis](https://github.com/darkroomengineering/lenis) (sin GSAP). Solo se anima el hero y la cinta de cartas.

Fluido para laptops (1280) hasta escritorio (1920+). Versión mobile pendiente.

## Correr
`python3 -m http.server 8000` y abrir http://localhost:8000

## Notas
- Tipografía: Chillax (si está instalada) con Outfit como respaldo (incluida en `fonts/`).
- Iconos: Iconsax (MIT). Fotos de producto: reemplazar la composición de `.foto` por fotos reales.
